# StanfordConvertXML

1. First, you need to create a database (PostgreSQL) to send data to.
2. For exporting data, the following information must be specified in the “db.conf” file (open the file with a text editor):
- Server IP address;
- Access port;
- Username;
- Password;
- Database name;
- Program name (default – StanfordConvertXML);
- Encoding system (default – UTF8).
3. After making changes to the “db.conf” data file, open the program file “StanfordConvertXML.exe” and use the “OpenXML” menu option to perform the data import.
